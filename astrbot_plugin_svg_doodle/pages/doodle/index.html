用法

        

          
聊天里：/涂鸦 戴着耳机听歌，她就会画一张发出来。

          
模型自动画：她有一个 draw_doodle 工具，聊到需要画的时候会自己调。

          
翻旧画：recall_doodle 工具，按关键词找以前画过的。

        

      

      

        
原理

        

          
模型不直接画像素，它写 SVG 代码（贝塞尔曲线 + 填充）。程序用 cairosvg 渲染成 PNG，再加纸张噪点、边缘抖动和签名。

          
这样线条连续、颜色干净，比逐图元拼贴更像简笔画。

        

      

      

        
常见调参

        

          
    
            
  • 画得太丑 → 改「角色外形描述」，用「圆脑袋…两个小圆点当眼睛…」这种画法描述，别写外貌形容词。
    • 
            
  • 头和身体断开 → 不用改，「身体结构约束」默认已按图层顺序写死。
    • 
            
  • 想要蜡笔感 → 「蜡笔纹理强度」调到 0.18~0.30。
    • 
            
  • 线条太抖/太直 → 调「线条抖动幅度」，0 = 笔直。
